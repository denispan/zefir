# Зефирные цветы Татьяны

Одностраничный сайт домашнего кондитера: зефирные тюльпаны, м. Аэропорт, Москва.

Astro 7 со статической сборкой, обычный CSS, JavaScript в браузере не нужен. Анимации — CSS:
букет в первом экране собирается при загрузке и медленно вращается, купол в блоке «Как я готовлю»
собирается при прокрутке (scroll-driven animations; где их нет, картинка показана собранной). При `prefers-reduced-motion` всё неподвижно.

## Запуск

Нужен Node.js 22.12+.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # сборка в dist/
npm run preview   # посмотреть сборку
npm run check     # astro check + tsc
npm run format    # prettier
```

## Что где менять

| Что                                      | Где                                              |
| ---------------------------------------- | ------------------------------------------------ |
| Наборы, цены, описания, фото             | `src/data/products.ts`                           |
| Отзывы                                   | `src/data/reviews.ts`                            |
| Телефон, Telegram, WhatsApp, MAX         | `src/data/site.ts` → `contacts`                  |
| Анонс к празднику                        | `src/data/site.ts` → `announcement`              |
| Сроки, предоплата, доставка, скидка      | `src/data/site.ts` → `terms`                     |
| Заголовок и описание страницы для поиска | `src/pages/index.astro` → `title`, `description` |

Анонс показывается до конца дня `until` (по Москве) и пропадает при следующей сборке после
этой даты. Чтобы убрать его сразу, поставьте `announcement = null`.

Ссылку на MAX Татьяна может взять в приложении: Настройки → QR-код → «Поделиться». Пока поле
`maxProfileUrl` пустое, MAX упоминается рядом с номером телефона.

## Фото

- `photos/raw/` — исходники с Авито (с водяными знаками).
- `photos/masks/` — маски «товар / фон», сделаны встроенным в macOS распознаванием объектов
  (`scripts/subject-mask.swift`).
- `npm run images` — убирает водяной знак, выравнивает баланс белого, осветляет фон и товар,
  кадрирует в 4:5 и кладёт результат в `src/assets/photos/`. Заодно собирает превью ссылки
  `public/og.jpg` и `public/apple-touch-icon.png`.

AVIF/WebP нужных размеров Astro делает сам при сборке.

Новое фото:

```bash
swiftc -O scripts/subject-mask.swift -o /tmp/subject-mask
/tmp/subject-mask photos/raw/new-photo.jpg photos/masks/new-photo.png
```

Затем добавьте запись в `PHOTOS` в `scripts/build-images.mjs` (кадр, участок фона для баланса
белого, экспозиция), запустите `npm run images` и подключите файл в `src/data/products.ts`.

Если будут оригиналы без сжатия Авито, их лучше положить в `photos/raw/` вместо нынешних.

## Публикация

**Vercel (черновик).** Импортируйте репозиторий, Astro определится сам. Пока не задана переменная
`SITE_URL`, страница закрыта от поисковиков (`noindex`, `Disallow: /`), чтобы адрес
`*.vercel.app` не попал в выдачу.

**Свой домен.** При сборке задайте адрес сайта — тогда появятся правильные canonical, sitemap и
индексация:

```bash
SITE_URL=https://ваш-домен.ru npm run build
```

Готовый `dist/` раздаёт любой веб-сервер (nginx, Caddy, Yandex Object Storage). Файлам из
`/_astro/` можно ставить вечный кеш: у них хеш в имени. Для Vercel это уже настроено в
`vercel.json`.

## После запуска на домене

1. Яндекс Вебмастер: добавить сайт, указать `sitemap.xml`, регион — Москва.
2. Яндекс Бизнес: карточка с районом, телефоном и ссылкой на сайт — для поиска по району это
   важнее самого сайта.
3. Google Search Console — то же для Google.
4. Яндекс Метрика — если нужна статистика.
